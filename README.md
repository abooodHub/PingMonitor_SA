# PingMonitor.SA.v1

تطبيق Windows لمراقبة البنق وتذبذب التأخير وفقد الحزم، بواجهة داكنة ودعم العربية والإنجليزية.

**PingMonitor.SA.v1 — التحديث 1.3.0.** [تحميل آخر إصدار منشور](https://github.com/abooodHub/PingMonitor_SA/releases/latest).

## التشغيل

يتطلب Windows 10 أو أحدث و.NET Framework 4.7.2. فك حزمة البرنامج بالكامل ثم شغّل `PingMonitor.SA.v1.exe` مع إبقاء ملف `.exe.config` بجواره.

[الإصدارات المنشورة](https://github.com/abooodHub/PingMonitor_SA/releases) · [سجل التغييرات](CHANGELOG.md) · [المقارنة وخطة ما قبل الرفع](docs/PRE-RELEASE-AR.md)

## المزايا

- 59 عنوان خادم فريدًا، مع تصفية المزودين وقوائم مراقبة مخصصة.
- بحث بالمدينة أو المزود أو العنوان وفرز رقمي للأعمدة.
- قياس متزامن بحد أقصى 8 طلبات، وعرض النتائج أثناء وصولها.
- نافذة تفاصيل ورسم لآخر 180 نتيجة من الجلسة، مع تصدير CSV.
- حركة خفيفة للأزرار والصفوف ومؤشر التقدم، وخيار تقليل الحركة.
- حفظ اللغة وحجم النافذة وعروض الأعمدة والفرز والقوائم.

## جديد 1.3.0

- دعم تكبير العرض والتفاف الأدوات عند ضيق الشاشة.
- استيراد وتصدير القوائم مع معاينة قبل الدمج؛ التصدير لا يتضمن بيانات الجلسة أو التفضيلات.
- نافذة «حول البرنامج» عبر F1 أو قائمة «أدوات» في شريط الحالة.
- ملخص جلسة CSV، وتنبيه Windows اختياري بعد ثلاث محاولات ICMP متتالية بلا رد.
- [تفاصيل الإصدار وحدود التحقق](docs/RELEASE-1.3.0-AR.md) و[اختبارات الأجهزة الأخرى](docs/MANUAL-RELEASE-CHECKLIST-AR.md).

## الاستخدام

اختر المزودين من الشريط العلوي، أو أنشئ قائمة من «إدارة القوائم». البحث يغيّر الصفوف المعروضة فقط؛ تستمر مراقبة الخوادم المحددة التي أخفاها البحث.

انقر مرتين على خادم لفتح التفاصيل، أو استخدم القائمة بالزر الأيمن. `Ctrl+C` ينسخ عنوان الخادم، و`Ctrl+Shift+M` يبدّل تقليل الحركة.

## البيانات والقياسات

- تُحفظ القوائم وتفضيلات العرض في `%LOCALAPPDATA%\PingMonitor.SA\server-lists.v1.xml` داخل AppData المخفي افتراضيًا، وليس بجوار EXE. توجد نسخة احتياطية للاستعادة عند تلف الملف.
- يُحفظ معدل التحديث واختيارات المزودين عبر إعدادات مستخدم Windows.
- الفقد يعتمد على آخر 20 محاولة ICMP. أخطاء DNS والتنفيذ لا تُحسب حزمًا مفقودة. التذبذب هو متوسط فروق الاستجابات الناجحة المتجاورة ضمن النافذة نفسها.
- عدم استجابة ICMP لا يثبت انقطاع الخدمة؛ نافذة التفاصيل تعرض سبب آخر فشل.
- سجل القياسات في الذاكرة فقط؛ لتحتفظ به بعد إغلاق البرنامج صدّره إلى CSV.
- يُطلب عنوان WAN عند الضغط على زر إظهاره، عبر HTTPS إلى ipify، دون طلب تحديد موقع إضافي.

## البناء والاختبار

ثبّت Visual Studio أو Build Tools مع تطوير تطبيقات سطح المكتب لـ.NET وحزمة استهداف .NET Framework 4.7.2، ثم افتح `PingMonitor.sln`، أو نفّذ من جذر المشروع:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1 -Test
```

لإعادة البناء وتشغيل الاختبارات وإنشاء حزم التشغيل والمصدر مع SHA256:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1 -Package
```

الناتج في `release/`، وهو مستبعد من ملفات المصدر. تفاصيل المجلدات والاختبارات في [دليل التطوير](docs/DEVELOPMENT-AR.md).
