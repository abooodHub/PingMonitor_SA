# PingMonitor.SA.v1 — تشغيل بملف واحد

حمّل **PingMonitor.SA.v1.exe** وشغّله مباشرة. لم يعد ملف `.exe.config` مطلوبًا بجواره. تتوفر حزمة ZIP أيضًا لمن يفضل تحميل البرنامج مع التعليمات.

المتطلبات: Windows 10 أو أحدث و.NET Framework 4.7.2.

- تضمين إعدادات التشغيل داخل EXE وتجهيزها تلقائيًا داخل AppData.
- الحفاظ على الواجهة ودعم DPI والقوائم وتفضيلات المستخدم.
- إصلاح إعداد التشغيل الداخلي إذا تلف، وحماية تجهيزه عند فتح أكثر من نسخة.
- اختبار الحزمة النهائية قبل النشر، وتوفير SHA256 للتحقق من التنزيل.

للتحديث: أغلق البرنامج واستبدل EXE في المجلد نفسه. يمكنك حذف `.exe.config` القديم؛ قوائمك محفوظة في `%LOCALAPPDATA%\PingMonitor.SA`. ملف واحد للتوزيع؛ تبقى بيانات التشغيل والتفضيلات داخل AppData.

فحص العرض الآلي لا يغطي جهاز Windows نظيفًا أو تغيير DPI فعليًا بين شاشتين. تفاصيل التحقق في [ملاحظات 1.3.1](https://github.com/abooodHub/PingMonitor_SA/blob/main/docs/RELEASE-1.3.1-AR.md).
