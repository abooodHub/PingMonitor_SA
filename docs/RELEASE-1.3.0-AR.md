# PingMonitor SA 1.3.0 — تجهيز ما قبل النشر

نسخة محلية غير منشورة. يحافظ الإصدار على الواجهة الداكنة وأماكن الوظائف الأساسية، ويضيف أدوات فرعية عبر شريط الحالة وإدارة القوائم.

## تحسين العرض

- تفعيل PerMonitorV2 وإعلان توافق Windows وتشغيل التطبيق بصلاحيات المستخدم العادي.
- التفاف أدوات الشريط العلوي والمزودين عند ضيق المساحة بدل التداخل.
- تصحيح ارتفاع عناصر قائمة المراقبة وتكبير الأعمدة وحفظ عروضها بوحدات مستقلة عن التكبير.
- إبقاء أزرار إدارة القوائم والتفاصيل ضمن ارتفاع النافذة المتاح، وتصحيح مساحة عناوين محاور الرسم عند تكبير الخط.

## أدوات جديدة

- **حول البرنامج:** من «أدوات» في شريط الحالة أو F1، ويعرض رقم الملف ورابط GitHub ومجلد البيانات وزر فتحه.
- **استيراد وتصدير القوائم:** من إدارة القوائم. ملف XML مستقل يتضمن أسماء القوائم ومعرفات الخوادم فقط، دون التفضيلات أو السجل. يعرض الاستيراد معاينة للأسماء والتحديدات وإعادة التسمية والمعرفات التي ستُتجاهل. يضيف قوائم جديدة دون استبدال الموجودة؛ لا تُحفظ الإضافات محليًا إلا بعد الضغط على «حفظ».
- **ملخص الجلسة CSV:** من «أدوات». يغطي جميع الخوادم التي قِيست منذ بدء التشغيل، بما فيها المخفية لاحقًا. يحتفظ بعدادات الاستجابات والمحاولات بلا رد والأخطاء وأدنى وأعلى زمن، حتى بعد خروج العينات القديمة من سجل آخر 180 نتيجة.
- **تنبيه اختياري:** معطل افتراضيًا، ويمكن تفعيله من «أدوات». يُرسل إشعار Windows بعد ثلاث محاولات ICMP متتالية بلا رد، مرة لكل فترة عدم استجابة وبحد أقصى إشعار كل 30 ثانية. يعود جاهزًا لفترة جديدة بعد وصول رد. إعدادات Windows قد تمنع ظهور الإشعار. أخطاء DNS والتنفيذ تكسر تتابع المحاولات ولا تشغّل التنبيه.

## حماية بيانات القوائم

تُرحّل معرفات الخوادم القديمة أثناء الاستيراد. تُرفض الملفات ذات الصيغة أو الإصدار غير المدعوم، وتعريفات DTD، والملفات الأكبر من 1MB. يستورد الملف من 1 إلى 100 قائمة بحد أقصى 1000 معرف في القائمة؛ تبقى قائمة فارغة إذا لم يُعرف أي من معرفاتها مع توضيح ذلك في المعاينة. تُعاد تسمية الأسماء المكررة تلقائيًا وتُنشأ معرفات قوائم جديدة. التصدير يستبدل الملف المختار ذريًا بعد اكتمال كتابته.

## جاهزية المصدر والتوزيع

أُضيف ملف GitHub Actions للبناء والاختبارات بصلاحية قراءة المصدر فقط. يشغّل ملف CI ست مجموعات اختبار، ويُستثنى اختبار الشبكة ذات الطلبات المعلقة مع توضيح الاستثناء في المخرجات. أمر تجهيز الحزمة المحلي يشغّل المجموعات السبع، بما فيها اختبار التبديل، ثم يولّد حزم التشغيل والمصدر وبصمات SHA256.

حُدثت صفحة المشروع وصورها وتنسيق الجوال وتكبير الصور بلوحة المفاتيح. رابط التحميل يشير إلى آخر إصدار **منشور**، ولا يفترض أن 1.3.0 متاح على GitHub الآن.

## نطاق التحقق

فحص العرض يستخدم تكبير الحدود والخطوط إلى 100% و125% و150% و200% داخل عمليات اختبار، بالعربية والإنجليزية، مع مراجعة صور. هذه محاكاة لتوزيع العناصر وليست تغييرًا لإعداد DPI في Windows أو اختبارًا فعليًا للانتقال بين شاشتين.

فحص الحزمة يفك ZIP إلى مجلد معزول ويتحقق من ملف الإعداد وتحميل موارد WinForms وحفظ القوائم واستعادتها في مسار اختبار مستقل. هذا لا يعادل جهازًا نظيفًا. بقيت [قائمة التحقق على أجهزة أخرى](MANUAL-RELEASE-CHECKLIST-AR.md) واختيار ترخيص المصدر واسم صاحب الحقوق قبل إعلان اكتمال كل شروط النشر. لم يُرفع الكود ولم يُشغّل GitHub Actions على الخدمة بعد.

مرجع إعداد DPI: [Microsoft — High DPI support in Windows Forms](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/high-dpi-support-in-windows-forms). مرجع فحص GitHub: [checkout](https://github.com/actions/checkout) و[upload-artifact](https://github.com/actions/upload-artifact).
