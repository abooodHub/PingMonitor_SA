# التحقق الخارجي قبل النشر

هذه البنود غير منفذة على أجهزة مستقلة في جلسة التطوير الحالية. الفحوص الآلية المحلية لا تحل محلها.

1. جرّب حزمة التشغيل على Windows 10 ثم Windows 11 بحساب عادي، دون Visual Studio، مع وجود .NET Framework 4.7.2 أو إصدار متوافق أحدث.
2. شغّل EXE مباشرة من الحزمة، وتأكد من عدم طلب صلاحيات المدير وعدم الحاجة إلى `.exe.config` بجواره. تحقق من تجهيز إعداد التشغيل داخل AppData ومن التشغيل مجددًا بعد حذف ملف التشغيل الداخلي دون حذف ملف القوائم.
3. جرّب تكبير Windows الفعلي 100% و125% و150% و200%، ثم الانتقال بين شاشتين مختلفتين في التكبير. افحص الواجهة الرئيسية والقوائم والتفاصيل وحول البرنامج ومعاينة الاستيراد.
4. غيّر عروض الأعمدة واللغة وحجم النافذة، وأعد التشغيل على الشاشة الأخرى؛ تحقق من ثبات التفضيلات وعدم تضخم الأعمدة تدريجيًا.
5. أنشئ قائمتين وصدّرهما، ثم استوردهما إلى حساب آخر. راجع المعاينة وجرّب الإلغاء قبل الدمج والإلغاء قبل الحفظ، ثم احفظ وأعد التشغيل.
6. فعّل التنبيه على خادم لا يرد على ICMP؛ تحقق من إشعار واحد بعد ثلاث محاولات، ثم استجابة وإخفاق جديد. راجع إعدادات إشعارات Windows إذا لم يظهر الإشعار.
7. صدّر ملخص الجلسة وافتحه ببرنامج جداول يدعم UTF-8. لا تعتبر عدم استجابة ICMP دليلًا قاطعًا على انقطاع الخدمة.
8. بعد رفع المصدر لاحقًا، راجع نتيجة GitHub Actions. اختر ترخيص المصدر وبيانات صاحب الحقوق، ثم انشر الحزمة الفعلية وحدّث نص «المعاينة المحلية» في README وصفحة المشروع.

لتسجيل النتيجة، دوّن إصدار Windows والتكبير ورقم الملف 1.3.1.0 وأي مشكلة ظهرت. لا تغيّر رابط التحميل إلى ملف إصدار قبل وجوده على GitHub.
