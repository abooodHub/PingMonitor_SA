## PingMonitor.SA.v1 — التحديث 1.3.0

حمّل **PingMonitor.SA.v1.zip**، وفك الضغط، ثم شغّل **PingMonitor.SA.v1.exe** مع إبقاء ملف `.exe.config` بجواره. المتطلبات: Windows 10 أو أحدث و.NET Framework 4.7.2.

- إصلاح تأخر تبديل المزود وتحسين القياس المتزامن وحساب الفقد والتذبذب.
- قوائم مراقبة محفوظة في AppData مع استيراد وتصدير ومعاينة قبل الدمج.
- بحث وفرز رقمي وتفاصيل الخادم والرسم وتصدير CSV وملخص الجلسة.
- حركات خفيفة وخيار تقليل الحركة، وتحسين توزيع العناصر عند التكبير.
- أدوات إضافية: حول البرنامج، فتح مجلد البيانات وتنبيه اختياري بعد ثلاث محاولات ICMP بلا رد.

القوائم لا تُحفظ بجوار EXE. التنبيهات معطلة افتراضيًا. السجل التفصيلي يحتفظ بآخر 180 نتيجة لكل خادم في ذاكرة الجلسة؛ صدّر البيانات للاحتفاظ بها.

اجتازت النسخة اختبارات المنطق والقوائم والاستيراد والقياس والحركة ومحاكاة العرض باللغتين. اختبارات التكبير محاكاة، وليست اعتمادًا على كل أجهزة Windows أو الشاشات. عدم استجابة ICMP وحده لا يثبت انقطاع الخدمة. بصمات SHA256 مرفقة للتحقق من الملفات.
